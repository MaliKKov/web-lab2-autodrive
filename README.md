# AutoDrive — интернет-магазин автотоваров

Лабораторная работа №2 по дисциплине «WEB-программирование».

**Тема:** «Верстка сайта по макету. Адаптивная верстка».

**Вариант №1:** Автомагазин.

## Описание проекта

AutoDrive — учебный многостраничный интернет-магазин автомобильных товаров, запчастей и аксессуаров.

Сайт разработан с использованием HTML5 и CSS3. Дизайн создан самостоятельно.

## Использованные технологии

- HTML5 — структура веб-страниц и формы.
- CSS3 — стилизация, позиционирование и адаптивная вёрстка.
- CSS Grid и Flexbox — размещение элементов.
- CSS Transform и Transition — анимации и плавные переходы.
- Media Queries — адаптация под разные размеры экрана.
- Microsoft Visual Studio — среда разработки.

## Структура проекта

- `index.html` — главная страница магазина.
- `catalog.html` — каталог автомобильных товаров.
- `product.html` — подробная страница товара.
- `cart.html` — демонстрационная корзина.
- `contact.html` — форма обратной связи с HTML5-валидацией.
- `css/styles.css` — таблица стилей сайта.

## Функциональные возможности

- Навигация между страницами.
- Карточки товаров и категории.
- CSS-трансформации и плавная анимация.
- Адаптивная вёрстка.
- Проверка полей формы средствами HTML5.

Поиск, сортировка и корзина являются демонстрационными. Реальные покупки не осуществляются.

## Адаптивность

Вёрстка рассчитана в том числе на ширину экранов 320, 768, 1000 и 1280 пикселей.

## Запуск проекта

1. Скачать ZIP-архив репозитория.
2. Распаковать файлы.
3. Открыть `index.html` в браузере.
4. Использовать меню для перехода между страницами.
